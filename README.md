# યોગા શોધક · Lenovo YT3-X90F

Lenovo Yoga Tab 3 10 Wi‑Fi (`YT3-X90F`) માટે ગુજરાતી ભાષામાં બનાવેલી એક નાની software compatibility finder વેબ એપ્લિકેશન.

તેમાં તમે Android વર્ઝન, RAM અને ખાલી સ્ટોરેજ પસંદ કરી શકો છો અને તેના આધારે હળવી એપ્સ, તેમની minimum requirements, સુરક્ષિત સોર્સ અને ઇન્સ્ટોલેશન ચેકલિસ્ટ જોઈ શકો છો.

> આ એક માર્ગદર્શિકા છે. એપ ઇન્સ્ટોલ કરતાં પહેલાં તેના અધિકૃત Play Store અથવા F-Droid પેજ પર વર્તમાન minimum Android અને ડિવાઇસ compatibility જરૂર ચકાસો.

## સ્થાનિક રીતે ચલાવો

```bash
npm install
npm run dev
```

Vite સર્વર `0.0.0.0` પર ચાલે છે જેથી live preview ઉપલબ્ધ રહે છે.

## પ્રોડક્શન બિલ્ડ

```bash
npm run build
npm run preview
```
